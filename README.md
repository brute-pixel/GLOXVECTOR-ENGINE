## About

GloxVector Engine is a long-term personal project focused on learning and mastering:

- Graphics Programming
- Game Engine Architecture
- Rendering
- Physics
- Mathematics for Graphics
- Software Engineering
- Performance Optimization

The engine is being developed from scratch to understand how modern game engines work internally, rather than relying on existing engines.

---

## Vision

The goal of GloxVector Engine is to become a fully featured educational game engine while serving as a software engineering portfolio project documenting years of continuous development.
